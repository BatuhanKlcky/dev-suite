# Changelog

All notable changes to this project will be documented in this file.

## [1.1.0] - 2026-11-23

### Added
- Official GitHub Action (`action.yml`) with `path` and `min-score` inputs, `score` and `grade` outputs, and rich Job Summary tables.

## [1.0.0] - 2026-11-23

### Added
- Initial release of `repo-pulse` CLI.
- 15 checks across Documentation, Community & Governance, Engineering & CI, and Hygiene & Metadata.
- `--fix` and `--dry-run` scaffolding for `LICENSE`, `CONTRIBUTING.md`, `.gitignore`, GitHub Issue/PR templates, and stack-aware CI workflows.
- `--json` and `--min-score <n>` flags for CI integration.
